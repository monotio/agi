# Adventure briefs

Pick an example in the app and edit it before generating, or write an idea of
your own. A few sentences are enough to start:

> I'm the night porter at a seaside hotel. Every guest is a ghost, but nobody
> has told the new manager. Help them finish their holidays before checkout.
> Cozy, funny, rainy. Start at reception with a ringing bell and a wet suitcase.

Tell the agent who we're playing, what we want and what kind of adventure it
should feel like. It fills in the rooms, characters and playable details.

These four examples add a cast, an opening scene and a few scored milestones.
The agent invents the puzzles and connects the story. Borrow whatever helps
your idea; you can leave the details for it to work out.

| Adventure                                         | The idea                                                                     |
| ------------------------------------------------- | ---------------------------------------------------------------------------- |
| [Knight's Trial](knights-trial/SKILL.md)          | A squire brings three impossible treasures home to a fading kingdom.         |
| [Badge of Millhaven](badge-of-millhaven/SKILL.md) | A rookie follows a delivery driver's story through a small-town mystery.     |
| [Mop Jockey](mop-jockey/SKILL.md)                 | A custodian takes back an invaded space station with the tools of his trade. |
| [Polyester Nights](polyester-nights/SKILL.md)     | One good suit, a midnight draw and a chance to be somewhere else.            |

The examples live in `SKILL.md` files. Their opening metadata supplies the
name and description; the Markdown below it is the editable game brief.
