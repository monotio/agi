# Support

Start with the [documentation](docs/README.md), the app's **Help**, and
[testing compatibility](docs/testing.md#testing-compatibility).

Ask usage questions and share games you made in
[Discussions](https://github.com/monotio/agi/discussions); say what you want to do
and what you tried. For a defect, choose **Bug report**;
for an imported game, choose **Game compatibility** and include its edition,
WORDS.TOK hash and interpreter profile. Screenshots and exact steps help.
Share original or redistributable examples and remove API keys and private chats
from attachments.

Use [private vulnerability reporting](SECURITY.md#reporting-a-vulnerability)
for security concerns and [conduct reports](CODE_OF_CONDUCT.md).
